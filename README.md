# Amazon Review Sentiment Classification

A text classification project for Amazon product reviews using TF-IDF features and multiple machine learning models.

## 1. Project Overview

This project focuses on sentiment classification of Amazon product reviews.

The workflow includes:

- Data preprocessing
- Text feature extraction
- TF-IDF vectorization
- Classification model training
- Model evaluation
- Model performance comparison

The project demonstrates the basic workflow of applying traditional machine learning methods to text classification tasks.

## 2. Dataset

Dataset: Amazon Reviews Dataset

Source: [Kaggle - Amazon Reviews Dataset](https://www.kaggle.com/bittlingmayer/amazonreviews)

The dataset contains Amazon product review texts and their corresponding sentiment labels.

> Note: The dataset size and train/test split are based on the final version used in this project.
